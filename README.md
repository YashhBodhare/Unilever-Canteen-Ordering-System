# Unilever Canteen Ordering System

## Business Analysis Portfolio Case Study

This repository contains an independently prepared business analysis case study for an employee canteen ordering service. The scenario explores how employees could order lunch online, reduce time spent in canteen queues, improve meal availability, and have orders delivered to their workstations.

> **Portfolio context:** This is an educational case study reconstructed from supplied training materials. It does not represent a live Unilever implementation or an endorsement by Unilever. The source materials identify different submitters. The analysis and artifacts in this repository are newly organized and should be reviewed before being presented as personal project work. See [Source Notes](10_Source_Notes.md).

## Project at a glance

| Field | Summary |
|---|---|
| Business area | Workplace food service |
| Proposed change | Employee-facing online menu and ordering service with canteen fulfilment |
| Primary users | Employees, canteen manager, kitchen staff, delivery associates |
| Supporting stakeholders | HR/payroll, IT/operations, management, project team |
| Main outcomes in the training scenario | Shorter lunch queues, lower food waste and operating cost, more effective employee work time |
| Analysis status | Portfolio-level draft. Conflicting scope and target details remain in the decision log. |

## How to read the evidence

- **Source-supported** means the supplied materials contain related information or a diagram.
- **Analyst draft** means this repository turns the scenario into a clearer, testable artifact. It is a proposed analysis, not proof that interviews, workshops, tests, or implementation occurred.
- **Open decision** means the source versions conflict or omit enough detail that a business owner should confirm it.
- Targets from the training scenario are treated as draft targets until the baseline, measurement method, and approval owner are confirmed.
